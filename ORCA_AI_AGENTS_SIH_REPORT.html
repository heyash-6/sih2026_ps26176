2. Mathematical Formulations & Algorithms

2.1. Haversine Great-Circle Geodesic Distance

Calculates the true nautical distance over the Earth's curvature between departure port $(\phi_1, \lambda_1)$ and target PFZ $(\phi_2, \lambda_2)$:

Geodesic Formula Δφ = φ₂ - φ₁ (radians) Δλ = λ₂ - λ₁ (radians) a = sin²(Δφ / 2) + cos(φ₁) · cos(φ₂) · sin²(Δλ / 2) c = 2 · atan2(√a, √(1 - a)) Distance (d) = R · c [where R = 6,371.0 km Earth Mean Radius]

2.2. Initial Forward Navigational Bearing

Computes the initial compass heading angle $\theta$ (0° to 360°) for vessel course plotting:

Nautical Heading x = sin(Δλ) · cos(φ₂) y = cos(φ₁) · sin(φ₂) - sin(φ₁) · cos(φ₂) · cos(Δλ) Bearing (θ) = (degrees(atan2(x, y)) + 360) mod 360

2.3. Ray-Casting Algorithm for Maritime Boundary Geofencing

Enforces International Maritime Boundary Lines (IMBL) and Marine Protected Areas (MPAs) using the Jordan Curve Point-in-Polygon theorem without requiring heavy external GIS server dependencies:

Spatial Topology For test waypoint (x, y) against polygon segment (p₁, p₂): If (y₁ > y) ≠ (y₂ > y): x_inters = (y - y₁) · (x₂ - x₁) / (y₂ - y₁) + x₁ if x < x_inters: inside = !inside Result: If total ray-boundary intersections are ODD, vessel is INSIDE restricted zone.

2.4. A* Risk-Aware Marine Pathfinding Algorithm

Discretizes the coastal waters into a grid and computes navigational corridors that avoid shallow shoals and turbulent sea cells:

Graph Search Cost Function f(n) = g(n) + h(n) + RiskPenalty(n) • g(n): Cumulative distance traversed from harbor • h(n): Haversine heuristic straight-line distance to PFZ destination • RiskPenalty(n): Dynamic penalty assigned to sea state cells with Hs > 2.0m or coral reefs

2.5. Deterministic Maritime Risk Score Model (0 to 100)

The Risk Engine evaluates 5 weighted components. No LLM is involved; it is 100% reproducible:

Deterministic Risk Matrix Total Risk (R) = (0.30 · R_wave) + (0.20 · R_wind) + (0.30 · R_hazard) + (0.10 · R_dist) + (0.10 · R_geofence) Component Scales: • R_wave: Hs < 0.8m → 10 | 0.8-1.5m → 25 | 1.5-2.2m → 55 | 2.2-3.2m → 85 | >3.2m → 100 • R_wind: < 15 km/h → 10 | 15-25 km/h → 30 | 25-40 km/h → 65 | >40 km/h → 100 (+Squall penalty) • R_hazard: LOW alert → 30 | MODERATE → 60 | HIGH → 85 | SEVERE / CYCLONE → 100 • R_dist: (Distance / 50km · 50) + (Trip Duration / 12h · 50) • R_geofence: CLEAR → 0 | NEAR BOUNDARY → 40 | INTERSECTS (Hard Block) → 100
⚠️ Non-Negotiable Hard Safety Floor Override

Regardless of short distance or high fishing potential, life safety takes absolute precedence:

If Significant Wave Height (Hs) ≥ 2.4m OR Sustained Wind ≥ 42 km/h OR Critical Hazard ≥ 85:
Total Risk = max(R, 65.0) → Automatically forces HIGH RISK Band and advises NO SAIL for small craft.

2.6. Composite Fishing Suitability Index (0 to 100)

Fishing Reasoning Equation Suitability (S) = 0.35(S_PFZ) + 0.20(S_Wave) + 0.20(S_Weather) + 0.10(S_Hazard) + 0.10(S_Ocean) + 0.05(S_Tide) • S_PFZ (35%): Satellite remote sensing confidence (SST gradient + Chlorophyll-a break) • S_Wave (20%): Wave stability factor (Calm sea ≤ 0.9m scores 92; dangerous sea > 2.4m scores 10) • S_Weather (20%): Wind speed (60%) + Precipitation intensity (40%) • S_Ocean (10%): Optimal SST window (26.5°C–29.5°C) + Chlorophyll concentration (≥ 1.0 mg/m³) • S_Tide (5%): Survey of India tidal harmonic clearance for bar harbors

4. Defense Q&A: Answering the Hardest Questions from Judges

Judge: "Why not use an end-to-end LLM (like GPT-4 or Claude) directly for the entire application?"
Answer: "An end-to-end LLM fails in marine decision support on three critical fronts:
1. Life Safety & Hallucination: An LLM cannot guarantee that a 2.5m wave will trigger a hard block. It might hallucinate safe clearance. Our deterministic risk engine guarantees life safety.
2. Speed & Cost: Passing 50 coordinate waypoints and ocean grid data through an LLM costs thousands of tokens and takes 6–8 seconds. Our deterministic Python engines calculate distance, routes, and risk in under 15 milliseconds.
3. Auditability: Maritime authorities require reproducible proofs. Two identical sea states must yield the exact same risk score every time."
Judge: "How does your system operate when a trawler loses internet 30 nautical miles offshore?"
Answer: "ORCA incorporates a 3-tier offline resilience fallback:
1. Rule-based Markdown Synthesis: If Gemini API calls time out, llm_client.py falls back to an embedded deterministic template generator that formats the findings cleanly without internet.
2. Native Pure-Python Ray-Casting: Our GIS agent runs native geometry algorithms without calling remote mapping APIs.
3. Local Coastal Gazetteer & Harmonic Tide Cache: Harbor coordinates and tidal tables are cached locally, allowing the boat to navigate safely while disconnected."
Judge: "How do you ensure multi-lingual answers don't mix English and Marathi/Hindi?"
Answer: "We enforce a strict single-language contract: ONE USER MESSAGE → ONE DETECTED LANGUAGE → ONE COMPLETE RESPONSE IN THAT LANGUAGE. Our NLU agent detects the script, and the Decision Agent passes an explicit negative constraint prompt forbidding English trailing summaries or mixed sentences."
