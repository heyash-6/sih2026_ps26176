System Overview

ORCA is an enterprise marine operational decision-support platform designed for coastal fishermen, maritime researchers, and port operators. It unifies satellite remote sensing (ISRO Oceansat, MODIS), real-time buoy telemetry (INCOIS), official astronomical tide predictions (Survey of India), and an AI agent copilot into an intuitive, tri-lingual web platform.

2. Step-by-Step System Workflow

Step 1: Access Control & Compulsory Authentication Gate

When a user opens the platform at http://localhost:8001:

  • App.jsx verifies currentUser state from localStorage.getItem('orca_user') and Supabase getSession().
  • If unauthenticated, access is completely blocked. The app renders a non-dismissible AuthModal with 12px backdrop blur, language selector, and demo/email login.
  • Signing in unlocks full portal access, while signing out locks the portal again.

Step 2: Automated Geolocation & Coastal Hub Resolution

  • Browser navigator.geolocation acquires GPS coordinates.
  • Backend /api/location/resolve calculates great-circle distance to the nearest Indian harbor using indian_coastal_registry.py.
  • The portal context dynamically switches to that port: fetching port-specific SST, wave heights, and tidal schedules.

Step 3: Multi-Source Marine Data Aggregation

  • GET /api/analytics: Retrieves 7-day SST, Chlorophyll-a front tracking, wave trends, and official Survey of India tidal harmonic predictions.
  • GET /api/pfz?port_id=...: Retrieves active satellite PFZs within 80km, ranked by confidence and depth.
  • GET /api/alerts?port_id=...: Fetches severity-sorted bulletins (Critical, Caution, Coastal bulletins).

Step 4: AI Conversational Copilot Query Execution

  • NLU Agent: Extracts intent, entities (port, time window), and user language (English, Hindi, Marathi).
  • Orchestrator: Dispatches tasks in parallel to Marine, Weather, and GIS agents.
  • Marine Agent: Queries satellite PFZ candidates from Supabase or live telemetry.
  • Weather Agent: Pulls forecasted wave swell and wind velocity.
  • GIS Agent: Calculates Haversine distance, nautical bearing, and runs ray-casting polygon checks to avoid restricted military or international zones.
  • Risk Engine: Applies deterministic 5-factor mathematical weighting to calculate an objective risk score (0–100) and checks tidal departures.
  • Decision Agent: Gemini Flash-Lite formats the evidence into a pure, single-language markdown response with interactive action buttons.
  • Database Persistence: Chat turns are saved to Supabase chat_messages and local cache, enabling instant drawer recall.

5. Mathematical Formulations & Algorithms

5.1. Haversine Great-Circle Geodesic Distance

Geodesic Formula Δφ = φ₂ - φ₁ (radians) Δλ = λ₂ - λ₁ (radians) a = sin²(Δφ / 2) + cos(φ₁) · cos(φ₂) · sin²(Δλ / 2) c = 2 · atan2(√a, √(1 - a)) Distance (d) = R · c [where R = 6,371.0 km Earth Mean Radius]

5.2. Deterministic 5-Factor Maritime Risk Score (0 to 100)

Deterministic Risk Matrix Total Risk (R) = (0.30 · R_wave) + (0.20 · R_wind) + (0.30 · R_hazard) + (0.10 · R_dist) + (0.10 · R_geofence) • R_wave: Hs < 0.8m → 10 | 0.8-1.5m → 25 | 1.5-2.2m → 55 | 2.2-3.2m → 85 | >3.2m → 100 • R_wind: < 15 km/h → 10 | 15-25 km/h → 30 | 25-40 km/h → 65 | >40 km/h → 100 (+Squall penalty) • R_hazard: LOW alert → 30 | MODERATE → 60 | HIGH → 85 | SEVERE / CYCLONE → 100 • R_dist: (Distance / 50km · 50) + (Trip Duration / 12h · 50) • R_geofence: CLEAR → 0 | NEAR BOUNDARY → 40 | INTERSECTS (Hard Block) → 100
⚠️ Non-Negotiable Safety Override

If Significant Wave Height (Hs) ≥ 2.4m OR Sustained Wind ≥ 42 km/h OR Critical Hazard ≥ 85:
Total Risk = max(R, 65.0) → Automatically forces HIGH RISK Band and advises NO SAIL for small craft.

5.3. Composite Fishing Suitability Index (0 to 100)

Fishing Reasoning Equation Suitability (S) = 0.35(S_PFZ) + 0.20(S_Wave) + 0.20(S_Weather) + 0.10(S_Hazard) + 0.10(S_Ocean) + 0.05(S_Tide) • S_PFZ (35%): Satellite remote sensing confidence (SST gradient + Chlorophyll-a break) • S_Wave (20%): Wave stability factor (Calm sea ≤ 0.9m scores 92; dangerous sea > 2.4m scores 10) • S_Weather (20%): Wind speed (60%) + Precipitation intensity (40%) • S_Ocean (10%): Optimal SST window (26.5°C–29.5°C) + Chlorophyll concentration (≥ 1.0 mg/m³) • S_Tide (5%): Survey of India tidal harmonic clearance for bar harbors

6. Offline Resilience & Fault Tolerance Matrix

Failure Mode Module Automated Fallback Mechanism
Gemini API Unavailable / Quota Limit llm_client.py Catches network exception and switches to local rule-based Markdown synthesis engine. Zero app crashes.
Cloud Database Disconnected supabase_client.py Fails over to browser localStorage and local Indian coastal benchmark registry (indian_coastal_registry.py).
GIS C-Libraries Missing gis_agent.py Falls back to our pure-Python Jordan Curve ray-casting algorithm for 2D point-in-polygon boundary validation.
GPS Inactive / Inland Coordinate nlu_agent.py Detects inland location and routes voyage from the nearest coastal hub automatically.
